# sacred

Sacred is a unity made game made by @xen-lol, i made this game because i wanted to create a "horror" game for people whoe enjoy chases. 

# whats the gameplay like?
- The gameplay summed down:
  * A monster is chasing you, you need to find 1 key for the first level, then 3 or more keys going on, do so and find the elevator, be careful; the monster could be anywhere, beware, the lights could go out at any moment, you have an equipped flashlight you toggle with 'F'.
